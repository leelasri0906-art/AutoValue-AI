# AutoValue AI — Car Selling Price Prediction

This project uses the supplied `car data.csv` (Car Details from Car Dekho) and a Random Forest regression pipeline.

## Run

```powershell
python train_model.py
streamlit run app.py
```

The dataset is already included at `data/car data.csv`.


## UI Design
Updated with a full-page automotive background, dark glass sidebar, blue gradient hero, translucent glass form, and modern prediction button to match the supplied reference style.
